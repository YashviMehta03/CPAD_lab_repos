## Expense Manager Application using Widgets in React Native 

The Expense Manager is a mobile application developed using React Native and Expo to help users manage their income and expenses efficiently. The application provides a simple and interactive interface for recording transactions, categorizing them, and monitoring their financial balance.

The app allows users to add income and expense transactions by entering a title, amount, transaction type, and category. It displays a summary of the total balance, total income, and total expenses, which are automatically updated whenever a transaction is added or deleted. The application also includes input validation to prevent invalid entries and displays an appropriate alert when incorrect data is entered.

The user interface is built using reusable components such as SummaryCard, CategoryChip, AddForm, and TransactionItem. React Native components like View, Text, TextInput, TouchableOpacity, and FlatList are used to create the layout and display the transaction list. State management is handled using the useState hook, while props and callback functions facilitate communication between components.

Overall, the application demonstrates the implementation of a component-based mobile application with interactive UI elements, transaction management, input validation, and automatic calculation of financial summaries.
