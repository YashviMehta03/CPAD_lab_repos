# Lab 9 - Student Profile Card mobile application

The application developed in this experiment is a Student Profile Card mobile application. It presents student information, including a profile image, name, course details, and a list of skills or technologies.

The user interface is designed using various widgets such as ContentPage, StackLayout, Grid, Label, Image, Frame, Button, Entry, and ListView/CollectionView. These controls are arranged using layout containers to create a structured and user-friendly interface.

The application also demonstrates basic interactivity through a Like button, which updates its displayed count when tapped, and a comment input field that allows the user to enter text. A horizontally scrollable skills section enables users to view the available skills. The experiment illustrates how XAML is used to define the user interface and C# code-behind is used to implement event-handling logic.

Overall, the application demonstrates the use of common Xamarin.Forms widgets, layout management, user input, and event handling in cross-platform mobile application development.
